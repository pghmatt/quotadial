# Keyword map, quotadial.com

Written 2026-10-25 from Google US English desktop results (DataForSEO SERP API, live advanced,
location 2840, 02:51 to 02:52 UTC). Volumes: bucketed 12-month averages from DataForSEO's Google Ads
search volume, United States, captured the same minute; estimates, not counts. Site status: new,
not deployed, not indexed. Search Console: not yet (the domain is Matt's to attach, #51).

The study itself, with the pages compared and their captures, is private (competitor research stays
out of this repository, `docs/PUBLIC_SCOPE.md`); this map is QuotaDial's own plan.

## Route classification

- SEO routes (each has a blueprint in `docs/seo/blueprints/`): `/`.
- Utility routes (descriptive H1s, never the home phrase): `/download`, `/pro`, `/key` (not
  indexed), `/privacy`, `/support`, `/changelog`, and from item 12 `/install` and `/cli`.

## What the results show (observed)

- "claude usage tracker" (about 1,900 a month): app-store and browser-extension listings, Claude's
  own docs, two product sites and discussions. Intent: looking for a tool. AI Overview present.
- "claude code usage monitor" (about 720): open-source monitors, extensions, one paid menu-bar app,
  discussions. Same intent.
- "codex usage limit" (about 1,300), "claude usage limit" (about 4,400), "codex usage" (about
  12,100): what the limits are and how to check them; official pricing and help pages own them.
  Not this site's intent today; a guide per provider is a later idea, recorded here.
- Related searches ask for Windows, for free, and for GitHub: QuotaDial is all three.
