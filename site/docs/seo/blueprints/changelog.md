# Blueprint: /changelog (utility)

Job: show `CHANGELOG.md`, newest first, rendered at build time, so a person can see what an update
brings (the same text the app's Help shows). H1: "What changed in QuotaDial". Each version an H2
with its date; Added, Changed, Fixed as H3s. Unreleased is labelled as not yet released. Closing:
"Download QuotaDial" (`data-primary-action`, `download_click`) and a link to the GitHub release notes.
Title: "Changelog: what changed in each version | QuotaDial" · Meta: "Every change people will notice
in QuotaDial, newest first: what each version added, changed and fixed, from the changelog the app
itself shows." (144)
